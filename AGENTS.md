# Orientações para agentes

Leia e respeite este `AGENTS.md` antes de trabalhar no projeto.

## Consulta de arquivos

- Antes de alterar código, consulte apenas os arquivos necessários para a tarefa.
- Não explore `build/`, `.dart_tool/`, assets binários ou arquivos Dart gerados sem necessidade.

## Arquitetura e escopo

- Siga MVVM + Repository + Riverpod.
- Preserve o código existente e evite refatorações fora do escopo da tarefa.
