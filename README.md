# Grimório RPG

Aplicativo Flutter para gerenciamento de RPG de mesa.

## Desenvolvimento

```sh
flutter pub get
flutter run
```

## Validação

```sh
dart format lib test
flutter analyze
flutter test
```

O projeto utiliza Riverpod e GoRouter, com organização por funcionalidades.
Credenciais e configurações locais devem permanecer fora do controle de versão.
